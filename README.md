## 📌 Hackathon Problem Statement (P3 · Ward Pulse)

In rapidly expanding Indian cities, municipal corporations (e.g. BBMP, PMC, BMC, LMC) allocate maintenance budgets and field personnel based on historical complaint logs. This approach breaks down catastrophically when:
1. **New or Delimited Wards are Created**: Newly absorbed peri-urban areas have **zero logged complaint history**.
2. **Under-Reporting & Digital Divide**: Low-income or newly regularized localities lodge fewer digital portal grievances, leaving their infrastructural decay invisible.
3. **Budget & Staffing Guesswork**: Municipal engineers are assigned reactively after crises occur rather than proactively on Day 1.

**Ward Pulse solves this zero-history challenge** by correlating physical ward attributes (population, road length, streetlights, parks, lakes, and spatial neighbor lag) to forecast monthly complaint volume across **6 civic categories**, predict uncertainty intervals, and recommend equitable field staff rosters.

### The 6 Official Competition Categories
1. **`electrical` (विद्युत)**: Streetlight failure, power fluctuation, transformers, dark spots.
2. **`solid_waste` (ठोस कचरा)**: Garbage accumulation, bin clearance, waste dumping.
3. **`roads` (सड़क व फुटपाथ)**: Potholes, asphalt wear, footpaths, manholes.
4. **`trees` (पेड़ व उद्यान)**: Dangerous branches, fallen trees, park maintenance.
5. **`animals_health` (पशु व स्वास्थ्य)**: Stray animal control, public health, mosquito fogging.
6. **`other` (अन्य नागरिक सेवाएं)**: Storm water drains, encroachments, general civic issues.

## 🌟 Key Capabilities & PS Innovations

- **🎯 Zero-History Demand Forecasting**:
  - Automatically identifies the **40 Target Wards** that have zero historical complaint logs in the competition dataset.
  - Multi-variate OLS regression calibrated on the 156 historical wards using structural physical indicators.

- **🗓️ 18-Month Temporal Seasonality Engine**:
  - Models realistic civic swings across all 18 competition months (`2024-01` to `2025-06`).
  - **Monsoon surge (May–October)**: Spikes road damage (+35% to +55%), tree falls (+70% to +85%), and animal health (+25%).
  - **Summer peak (March–May)**: Spikes electrical transformer and power loads (+20% to +28%).

- **🗺️ Dual-Mode Interactive Visualization**:
  - **🗺️ Geo Map View (Leaflet / OpenStreetMap)**: Plots all 198 BBMP wards with heat pins, golden dashed halos for target wards, and tooltip inspect.
  - **⊞ Civic Grid View**: Grouped by BBMP administrative zones (Yelahanka, Mahadevapura, Bommanahalli, Dasarahalli, East, West, South, Rajarajeshwarinagar).

- **📥 One-Click Submission Exporter**:
  - Direct in-browser button: **"Export submission.csv"** instantly formats and downloads the 4,320 rows matching competition specs.
  - Python CLI alternative: `python src/model/train_predict.py` for automated pipeline execution.

- **👷 Day-1 Equitable Staffing Allocation**:
  - Converts predicted complaints into municipal field staff rosters (~1 worker per 16 monthly complaints).
  - Ensures zero-history wards receive staff and budget on Day 1.

- **📍 User Location & GPS Geocoding**:
  - Detects user live GPS coordinates (`navigator.geolocation`) or search any city (Bengaluru, Lucknow, Indore, Pune, Delhi).

- **🎛️ "Predict a New Ward" Interactive Simulator**:
  - Move sliders for population, roads, streetlights, and parks to simulate hypothetical ward demarcations with real-time recalculation.

- **🌐 Bilingual English & Hindi (हिंदी)**:
  - Complete municipal UI toggle with authentic Indian typography (`Yatra One` & `Mukta` fonts).

## 🚀 Quickstart Guide

### Option 1: Instant Browser Launch (Zero Installation)
Simply double-click [`dashboard.html`](dashboard.html) or [`index.html`](index.html) in any modern web browser:
1. View the live 198 wards of Bengaluru BBMP on the Leaflet map.
2. Select any month (e.g. `2024-06` to observe monsoon spikes).
3. Click **"Export submission.csv"** to download the competition file.

### Option 2: Python Command-Line Execution
Run the automated ML pipeline to regenerate predictions and verify metrics:

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run forecasting model and export submission.csv
python src/model/train_predict.py --features data/ward_features.csv --output data/submission.csv
```

### Option 3: Local Dev Server
```bash
# Using Node.js
npx serve -l 3000 .

# Or using Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000` or `http://localhost:3000`.
